# Austin Animal Center Prediction Model

# Overview
This project predicts the intake condition of cats entering the Austin Animal Center using machine learning methods in R.

# Methods
- Logistic Regression
- K-Nearest Neighbors (KNN)
- 10-Fold Cross Validation
- Hyperparameter Tuning

# Results
The final logistic regression model achieved approximately 83.6% accuracy on the test dataset.

# Tools
- R
- Tidymodels
- Tidyverse
- R Markdown
 
# Dataset
Austin Animal Center public intake data.

# Project Background
This project was completed as part of a university statistics/data science course in a team setting. The repository showcases the modeling, analysis, and reporting components of the project.
